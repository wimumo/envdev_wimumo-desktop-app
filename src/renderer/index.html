¿Qué es el dispositivo WIMUMO?

WIMUMO es un dispositivo inalámbrico capaz de medir señales eléctricas del cuerpo. La señal electrofisiológica o biopotencial más conocida es el electrocardiograma (ECG) con la que casi todo el mundo ha tenido experiencia en el consultorio médico en algún momento. Pero también se pueden medir otros biopotenciales, como los provenientes de los músculos (llamado electromiograma o EMG), del cerebro (EEG) o de los ojos (EOG).

WIMUMO mide estas señales, las transmite de forma inalámbrica a través de Wi-Fi y las utiliza para una variedad de aplicaciones, como generación de música, juegos y aprendizaje sobre las propias señales. Técnicamente lo llamamos plataforma de adquisición Multi-Modal, y de ahí su nombre (WIreless MUlti MOdal aqcuisition platform).

Objetivos de WIMUMO

WIMUMO no está destinado solo para ser utilizado por los profesionales que lo desarrollaron, sino que uno de sus objetivos es proporcionar un acceso simple y amigable a las señales producidas en el cuerpo humano. El poder motivador de las señales biopotenciales junto con el fácil acceso posibilita la generación de múltiples aplicaciones para la enseñanza, espectáculos artísticos, entretenimiento, dispositivos de ayuda para personas con discapacidad y muchas otras.

Es por ello que WIMUMO pone a su disposición las señales, aplicaciones y herramientas de configuración a través de una página web. En el caso de las actuaciones artísticas, las señales ya procesadas se transmiten para generar música, imágenes y más con programas estándar que utilizan músicos y diseñadores multimedia, basados en el protocolo OSC.

Uso de WIMUMO

WIMUMO tiene electrodos que miden señales eléctricas del cuerpo. Si los coloca sobre su cuerpo (con los contactos metálicos apoyados sobre la piel en una zona libre de pelo) podrá visualizar la actividad eléctrica de los músculos que se encuentren en ese lugar, cuando se contraigan. Si los apoya en su pecho incluso puede visualizar los latidos del corazón.

WIMUMO envía los datos de las señales que mide usando el protocolo OSC. Este protocolo es muy utilizado en programas de generación de multimedia. Con esta aplicación podrá ver las señales y controlar tonos musicales, pero sacará mayor provecho a WIMUMO creando lo que desee con aplicaciones tales como puredata y la muy conocida Processing (https://processing.org/). En la página del proyecto encontrará algunos ejemplos de Processing para comenzar a usar WIMUMO.

Haciendo uso de la función de redirección, también puede usar esta aplicación en conjunto con otras aplicaciones. Solo debe de seguir la guía de configuración. , conectar el WIMUMO, y luego poner los datos de su otra aplicación en la sección de redirección.

WIMUMO funciona con baterías de litio recargables tipo 14500 de 3.7 V. Si bien tienen el mismo tamaño, son distintas de las pilas AA comunes , y no funcionará si se intentan utilizar. Cuando la batería está baja, la luz indicadora titila en rojo y deberá retirarse la batería del equipo para recargar.

Para más información puede consultar la página del proyecto en gibic.ing.unlp.edu.ar/wimumo

Configuración del dispositivo WIMUMO - elegir guiá


El dispositivo WIMUMO se conectará a esta máquina por medio de una red Wi-Fi .
Para poder conectarlo, primero hay que configurar el dispositivo correctamente.


Configuración del dispositivo WIMUMO - En 7 pasos


Paso 0 - Material necesario
Paso 0 - Material necesario

Para seguir estas instrucciones necesitará: un dispositivo WIMUMO, una red Wi-Fi, y esta máquina.



Paso 1 - Conectar a la red Wi-Fi local
Paso 1 - Conectar a la red Wi-Fi local

Primero asegúrese de que la máquina está conectada a su red Wi-Fi local.

Busque su dirección IP local.

-> IP local detectada:

-> Windows 11: Entré a “Configuración” y luego a la sección de “Red & Internet”. Si se conecta a la red por Wi-Fi entre a la sección de Wi-Fi, si es por cable entre a “Ethernet”. Por último entre a las propiedades de su red local. Entre las propiedades encontrará su dirección IP local al lado de "dirección IPv4", tendrá la forma "x.x.x.x" (por ejemplo: 127.0.0.1). Para más detalles puede entrar a: Página oficial de Microsoft Windows

-> Linux: Para encontrar su IP local puede abrir una terminal, e ingresar el comando "ifconfig". Encontrará su dirección IP local al lado de "inet", tendrá la forma "x.x.x.x" (por ejemplo: 127.0.0.1).



Paso 2 - Encender WIMUMO en modo de configuración
Paso 2 - Encender WIMUMO en modo de configuración

Encienda el dispositivo WIMUMO.

Si es la primera vez que configura el dispositivo, este debería entrar en modo de configuración, indicado por el LED titilando rápidamente con varios colores.

/

-> LED titla lentamente con un color: Esto indica que está en modo “OSC” o modo de uso normal. Si WIMUMO no entró en modo de configuración automáticamente, entonces lo puede cambiar presionando el pulsador. El pulsador se encuentra en un agujero circular del dispositivo WIMUMO, para presionarlo necesitará un objeto largo y fino (por ejemplo: una aguja).

-> LED no prende: Asegúrese de que el dispositivo WIMUMO tiene batería antes de prenderlo. - Si no es la primera vez que estás configurando el dispositivo es posible que esté mal configurado. Para evitar el problema puede alejar el dispositivo de la red Wi-Fi mal configurada o apagar la red Wi-fi y reiniciarlo. Si logra que el LED se prenda entonces puede volver a prender la red Wi-Fi y retomar con la configuración del dispositivo.

-> Encender WIMUMO: Presione el botón de encendido, como se ve en la imagen



Paso 3 - Ingresar a la página de configuración
Paso 3 - Ingresar a la página de configuración

Ahora en esta máquina busque la red Wi-Fi WIMUMOxxx (por ejemplo: WIMUMO023), y conéctese con la contraseña “wifiwimumo”.

Con un navegador web (por ejemplo: Google Chrome) ingrese a la dirección " 192.168.0.2 ".

-> La red se desconecta: La red WIMUMOxxx se usa para configurar el WIMUMO, y no tiene conexión a internet, por lo que muchos dispositivos la ignoran. Para evitar que esto ocurra puede:

1. Poner esta máquina en modo avión y activar solo el wifi.

2. Ingresar a opciones de la red WIMUMOxxx y seleccionar que la máquina se conecte automáticamente.



Paso 4 - configurar red Wi-Fi
Paso 4 - configurar red Wi-Fi

Ya en la página de configuración, ingrese a "Configurar WiFi".

Seleccione su red Wi-Fi local entre las opciones e ingrese su contraseña. Asegúrese de ingresar bien la contraseña.

Los demás campos no son necesarios. Solo necesita hacer clic en “Aplicar”.

/

-> No aparece ninguna red Wi-Fi: Necesita esperar y apretar “Refrescar”. Asegúrese de re conectar la red WIMUMOxxx si se desconecta en el proceso.

-> ¿Se guardó la configuración?: Después de apretar "aplicar" la página solo responderá “configuración enviada”. No se preocupe, la configuración se guardó correctamente. Puede seguir con el siguiente paso.



Paso 5 - Configurar dirección
Paso 5 - Configurar dirección

Ahora haga clic en "Configurar OSC".

Ingrese la IP local que busco o detectó en el paso 1 y el puerto “4560” .

-> IP local detectada:

/

-> OSC (Open Sound Control) es un protocolo de envío de datos. Normalmente es usado para conectar en red sintetizadores, ordenadores y otros dispositivos multimedia. También es el protocolo que WIMUMO utiliza para enviar información. El "Modo OSC" del WIMUMO o "Modo normal", es el modo en donde el dispositivo constantemente envía datos por medio de este protocolo. 4560 es el puerto en el que esta aplicacion recive los datos.

-> Como conectar WIMUMO a otras aplicaciones: Utilizando el mismo proceso que usamos para conectar el dispositivo a esta aplicación es posible conectarlo a otras aplicaciones. Solo es necesario cambiar el número de puerto “4560”, por el puerto que otras aplicaciones utilizan para recibir mensajes.



Paso 6 - Cambiar a modo de uso normal
Paso 6 - Cambiar a modo de uso normal

Presione el botón “Modo OSC” en la aplicación de configuración, o el pulsador en el dispositivo para cambiar al modo de uso normal.

Desconectar esta máquina de WIMUMOxxx y conectar a su red Wi-Fi local



Último paso - Confirmar conexión
Último paso - Confirmar conexión

Si WIMUMO logró conectarse a la red Wi-Fi local, entonces verá el LED titilar lentamente con un único color.

Si WIMUMO logró conectarse a esta aplicación, el siguiente indicador lo confirmara:

-> WIMUMO Desconectado


/ / /

-> El LED se mantiene apagado cuando prendo el WIMUMO: Si sigue esperando y el WIMUMO no reacciona, en ninguno de los 2 modos, entonces es posible que se haya escrito mal la contraseña de la red Wi-Fi, o la dirección ip. Para solucionar el problema debería apagar la red Wi-Fi o alejar el WIMUMO del área de la red y reiniciar el mismo. Si logro que el LED titile de un color o varios colores entonces puede prender la red Wi-Fi y volver a configurar el dispositivo.

-> El LED titila de un color, pero no se conectó a esta aplicación: Espere un tiempo y confirme entrando a “Estado” que no se conectó el dispositivo. Asegúrese de que la máquina esté conectada a su red Wi-Fi local. Si siguió todos los pasos correctamente, es posible que la dirección IP o el puerto ingresados en el paso 4 fueran incorrectos. Presione el pulsador para devolver el dispositivo al modo de configuración y vuelva al paso 4. El pulsador se encuentra en un agujero circular del dispositivo WIMUMO, para presionarlo necesitará un objeto largo y fino (por ejemplo: una aguja). Asegúrese de que ingresó correctamente la Ip local de esta máquina y el puerto 4560.

-> Problemas con la Firewall: Es posible que la Firewall de esta máquina esté deteniendo los mensajes del WIMUMO, asegúrese de permitir mensajes dirigidos al puerto 4560.

-> Problemas con la IP: Es posible que la IP local de la computadora cambie al desconectarse y reconectarse a su red Wi-Fi local. En este caso lo mejor es hacer la configuración con la ayuda de un celular.
